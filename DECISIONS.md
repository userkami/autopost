| #   | Date       | Decision                                                                                                                                                                                                                                                                                                                                         | Reason                                                                                                                                                                                                                                                                                                                                                                             |

| 10  | 2026-10-09 | Use `next-auth@5.0.0-beta.32` (dist-tag `beta`; `latest` is still v4) + `@auth/drizzle-adapter@1.11.3`.                                                                                                                                                                                                                                          | PLAN §2 mandates NextAuth v5 (fallback Better Auth only "if v5 blocks you" — it did not block).                                                                                                                                                                                                                                                                                    |
| 11  | 2026-10-09 | Dev login creates a **database session row + Auth.js cookie directly** (`src/lib/dev-login.ts`) instead of an Auth.js Credentials provider.                                                                                                                                                                                                      | Verified in `@auth/core`: with `strategy: "database"` the credentials branch always issues a JWT cookie, and `session.js` reads cookies via `adapter.getSessionAndUser` — the login would silently never work. Core only rejects credentials when it is the _only_ provider. Cookie name/attrs copied from Auth.js `defaultCookies` (`authjs.session-token` / `__Secure-` prefix). |
| 12  | 2026-10-09 | `accounts` table stores Google login tokens in adapter-standard plaintext columns (not `_enc`).                                                                                                                                                                                                                                                  | Login requests identity-only scopes (`openid email profile`); the app never reads these tokens; the adapter owns the column writes. Blogger refresh tokens (sensitive scope) ARE encrypted in `blog_connections.refresh_token_enc` (Phase 3).                                                                                                                                      |
| 13  | 2026-10-09 | Adapter-contract additions beyond PLAN §5: `users.emailVerified`, `accounts.scope`, `sessions` PK = `session_token`.                                                                                                                                                                                                                             | Required by `@auth/drizzle-adapter` types (docs beat the plan, §0.3). `sessions` drops the UUID id for a token PK.                                                                                                                                                                                                                                                                 |
| 14  | 2026-10-09 | Closed value sets from §5 implemented as Postgres **enums** (`pgEnum`), provider names stay `text` unions.                                                                                                                                                                                                                                       | Enums enforce the plan's exact values at the DB level; providers are extended by the Phase 2 registry, so text + TS union.                                                                                                                                                                                                                                                         |
| 15  | 2026-10-09 | `provider_catalog` unique on `(provider, role, model_id)`; seeds use `ON CONFLICT DO NOTHING`.                                                                                                                                                                                                                                                   | Makes `db:seed` idempotent and non-destructive — re-running never overwrites admin edits (settings rows likewise).                                                                                                                                                                                                                                                                 |
| 16  | 2026-10-09 | Seed only **docs-verified** model IDs (checked 2026-10-09): OpenAI `gpt-6-luna`/`gpt-6.1-sol`/`gpt-6-astra` + `gpt-image-2` (plan §8.2), Gemini `gemini-3.8-flash`/`gemini-flash-latest`/`gemini-nano-banana-2.1`, Anthropic `claude-sonnet-5-5`/`claude-opus-5-5`/`claude-haiku-5-5`. No seeds for openrouter/pollinations/fal/leonardo/custom. | §0.4: model IDs are data; never invent them. | 17  | 2026-10-09 | Settings loader failures fall back to typed defaults + error log (inside the store).                                                                                                                                                                                                                                                             | Availability: a settings read must never 500 a request; DB health is surfaced separately by `/api/health`.                                                                                                                                                                                                                                                                         |
